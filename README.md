# Md. Saddam Hossain — Professional Portfolio

This is a personal portfolio website built to showcase the professional profile, experience, education, certifications, skills, and contact details of Md. Saddam Hossain.

## Overview

The website presents a modern, responsive portfolio for an IT and Printing Technology professional with 18+ years of industry experience and a current focus on Computer Science & Engineering studies.

## Features

- Responsive and mobile-friendly design
- Smooth animations and interactive UI elements
- Dark/light theme support
- Sections for:
  - Home / Hero
  - About Me
  - Experience
  - Education
  - Certifications
  - Skills
  - Projects
  - Contact

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html — main website page
- css/ — stylesheets for layout, components, sections, and responsiveness
- js/ — animations, navigation, theme, and app behavior
- assets/images/ — images and visual assets

## How to Run

Option 1: Open the project directly in a browser
1. Open `index.html` in your browser.

Option 2: Run a local server
1. Open the project folder in your terminal.
2. Run:
   `python -m http.server 8000`
3. Open: `http://localhost:8000`
